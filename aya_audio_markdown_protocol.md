# MODULE 2 : FICHIERS AUDIO REÇUS D'AYA (TRADUCTION TEXTE BRUT MARKDOWN)

## 📌 OBJECTIF
Traiter et traduire rapidement un fichier audio reçu d'Aya en Texte Brut Markdown (`.md`) sans générer de vidéo ni de fichier `.ASS`.

## 🛠️ WORKFLOW AUTOMATIQUE
1. **Renommage Fichier Source** :
   - Le fichier audio reçu d'Aya est renommé en `Audio à traduire.[ext]` (ex: `Audio à traduire.ogg`).
2. **Traduction Multimodale Brut (Protocole V3 Gold Standard)** :
   - Traduction intégrale du premier au dernier mot sans résumé ni coupure.
   - Sens sélectionné : **Arabe Palestinien ➔ Français** OU **Français ➔ Arabe Palestinien (Gaza Ammiya)**.
3. **Génération Fichier Markdown (`.md`)** :
   - Création du fichier `.md` inspiré des règles du Protocole V3 contenant uniquement le Texte Brut de Haute Qualité.
